## Реальный путь вызова

Локальная конфигурация: Groq → Gemini → OpenRouter. Конфигурация сервера
может отличаться, её точные значения без доступа к серверу не подтверждены.
Groq: `openai/gpt-oss-120b`, в fast-вызовах вариантов/живого диалога
120b → 20b, с перебором ключей и кулдауном (model, key) на 429.
Это открытые веса через Groq, **не платный OpenAI API**.
Gemini: для fast первыми 3.5/3.1 Flash Lite; в обычных вызовах 3.1/3.5 Lite,
затем остальные настроенные Flash, обе Gemma в конце. Состав задаёт
`GeminiProvider._cascade_for_call`/`_MODEL_CASCADE` в llm.py.
Это имена в коде, не утверждение о текущей доступности всех моделей у Google.
OpenRouter: `openrouter/free`, фактически выбранную модель нужно брать из ответа.

| Действие | Контекст и штатные логические вызовы |
|---|---|
| Варианты ответа | Входящее + карточки стиля/собеседника + сигналы/примеры; 3 варианта одним вызовом, лимит 1800 выходных токенов |
| Другие варианты | Новый вызов; передаются прежние варианты, кэш пропускается |
| Живой диалог | Стиль, заметки, хвост до 8 реплик; варианты и новые заметки одним вызовом, лимит 1700 |
| Анализ | Метрики всей истории локально; LLM получает факты и до 20 последних строк, до 300 символов на строку и 3000 суммарно; лимит 1700 |
| Свидание | Выборки сообщений, карточка собеседника, признаки; идея и подарки одним вызовом, лимит 1200 |
| Подготовка карточек | Лениво: отдельные вызовы стиля, собеседника, стиля с контактом, общего стиля; до основного ответа возможны дополнительные вызовы |
| Фоновая пересборка | Первый порог 15, далее 50 новых сообщений; выборки до 150 сообщений, до 3 вызовов: стиль с контактом, собеседник, общий стиль |
| Голос | Отдельная транскрипция Whisper large-v3-turbo, fallback Gemini gemini-flash-latest; затем возможна текстовая генерация |

`_fit` ограничивает выборки в соответствующих построителях 12000 символами;
это не универсальный лимит всего промпта. Для live заметки и входящий текст
могут увеличивать контекст. Карточки используют разные лимиты 1100–2000.
Groq добавляет буфер reasoning: fast +300, другие вызовы +900; OpenRouter +900.
`max_tokens` — потолок, не измеренный расход.
Кэш вариантов/живого диалога живёт 7 дней; анализ и свидание имеют отдельные
сохранённые результаты/условия обновления. Кэш может устранить основной вызов,
но не гарантирует отсутствие предшествующей подготовки.
Перегенерация, исправление результата rewrite, ошибки валидации, перебор
ключей и моделей увеличивают HTTP-попытки. Автоматической предгенерации
вариантов на каждое входящее нет: фоновые вызовы относятся к карточкам.

## Новый учёт

`llm_usage.py` пишет JSONL вне репозитория и bot.db:
`~/.local/state/cueme/llm_usage/usage.jsonl`, ежедневная ротация, 60 архивов.
Путь меняется через LLM_USAGE_DIR, отключение LLM_USAGE_ENABLED=false.
На каждый POST: UTC, функция, запрошенная/ответившая модель, токены
input/cache/output/reasoning, длительность, HTTP-исход, номер попытки,
связь с логическим вызовом и действием. Валидация записывается отдельно,
так что отклонённый, но оплачиваемый ответ не теряется.
Reasoning входит в output и повторно к цене не прибавляется.
Неизвестный usage/cache/tariff — null с причиной; неизвестный расход не $0.
Сбой записи не ломает генерацию; отменённый запрос отмечается неизвестным.
Не записываются тексты, ответы, URL, ключи и Telegram ID.
Ключ Gemini перенесён из URL в x-goog-api-key: INFO httpx больше не печатает его.
Старые журналы этим не очищаются; ранее раскрытые ключи требуют замены отдельно.

Отчёт на сервере из каталога проекта:

```sh
venv/bin/python -m tools.llm_cost_report --days 7
```

Сводка: функции/модели, повторы, неизвестный расход, подтверждённые успешные
действия, стоимость всех попыток на успешное действие, отдельно фон и тесты.
Цена по тарифу не равна инвойсу. Прогноз 30 дней даётся лишь при наличии
измерений/тарифов; это экстраполяция наблюдавшегося темпа, не гарантия нагрузки.
Простой/потери журнала не проверяются автоматически.
Есть отдельный сценарный пересчёт измеренных текстовых токенов на кандидатов:
без скидки кэша, с диапазоном peak/off-peak DeepSeek. Неизвестные попытки явно
исключены; такой частичный прогноз **не полный бюджет**. Токенизаторы, длина
ответов и число повторов при смене модели могут измениться.

## Админский тест без влияния на пользователей

`tools/bench_paid_models.py` — утилита оператора сервера, не команда обычного
пользователя. Не читает bot.db, не запускает polling и не меняет провайдеров.
7 вымышленных ситуаций, реальные построители промптов бота, одинаковый SHA256
промпта для каждой модели. Отдельные режимы:

```sh
venv/bin/python -m tools.bench_paid_models
venv/bin/python -m tools.bench_paid_models --check-models
# ПЛАТНЫЙ запуск — только после добавления ключей и выделения бюджета:
venv/bin/python -m tools.bench_paid_models --run --budget-usd 2 --repeats 3
```

По умолчанию только подготовка без сети. GET /models проверяет видимость
моделей аккаунту, но не гарантирует квоту/успех генерации.
Платный запуск требует обе пары ключей OPENAI_API_KEY и DEEPSEEK_API_KEY
через config.py/.env, явный бюджет ≤$5. Полный резерв проверяется ДО первого
запроса, чтобы не получить неравное число прогонов. Резерв основан на
UTF-8 байтах + запасе, а не выдаётся за измеренные токены; таймаут не возвращает
его в доступный бюджет. Списания провайдера всё равно нужно сверять с кабинетом.
По текущим 7 промптам 84 запроса (4 модели × 7 × 3), резерв $1.891417.
Повторов HTTP внутри теста нет: ошибки остаются в результате.

Выход: файл с ответами только вымышленных ситуаций, кандидаты A–D,
задержка, usage, цена, валидность русского/маркеров/числа вариантов.
Ключ соответствия моделей вынесен в blind_mapping того же JSON: для слепой
оценки не показывать его оценивающему. Оценка человеком 1–5: естественность,
голос автора, уместность, уважение границ, конкретность.
Автовалидатор не объявляет ответ качественным только по правильному формату.
Тестовый расход отдельно исключается из производственного прогноза.

Сейчас оба ключа отсутствуют; реальный сравнительный тест НЕ запускался.
Качество, задержка и стоимость ответов кандидатов не измерены; победителя нет.
Экономичный первый кандидат по прайсу — Luna, пара для проверки — DeepSeek
Flash; Terra/Pro нужны как ориентир качества. Это план эксперимента, не
рекомендация переключить пользователей.

Для бюджета нужны минимум несколько полных дней измерений, лучше 7–14,
плюс оплаченный тест и сверка с кабинетом. За рамками: налоги, курс валют,
платёжные комиссии, сервер, кредиты/free-tier, недоступные старые вызовы,
неподдержанные тарифные режимы и цена аудио без длительности.
